Estructures de dades Vectors (Arrays) amb FOREACH JavaScript

Observa el fitxer de JavaScript i el resultat de la consola.

// Exemple d'ús de Vectors amb FOREACH

      const enemics = [
        { nom: 'Goblin', vida: 50 },
        { nom: 'Orc', vida: 100 },
        { nom: 'Troll', vida: 150 },
      ];

      let atacJugador = 40;

      //Atacant tots els enemics!

      enemics.forEach(enemic => {
        enemic.vida -= atacJugador;
        // Enemic X - Vida restant: X
      });
